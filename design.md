# Sweet Toys — Design System

## Brand Identity
- Company: Sweet Toys
- Type: Plastic toy manufacturer (B2B catalog)
- Audience: Wholesale buyers, retail shop owners, distributors

## Color Palette
- Primary Dark: #1A2B4A (deep navy — trust, professionalism)
- Primary Mid: #2E5090 (medium blue — links, accents)
- Accent: #E8F0FC (light blue tint — backgrounds, highlights)
- White: #FFFFFF
- Light BG: #F7F9FD
- Text Dark: #1A2B4A
- Text Medium: #4A5568
- Text Light: #718096
- Border: #CBD5E0
- Success/Category1: #EAF5EA
- Category Pill Cars: #EEF4FF (blue tint)
- Category Pill Animals: #F0FAF0 (green tint)

## Typography
- Heading Font: 'Sora', sans-serif (Google Fonts) — strong, modern, distinctive
- Body Font: 'Inter', sans-serif — clean, readable
- Fallbacks: system-ui, sans-serif

## Layout
- Max content width: 1200px, centered
- Header: sticky, dark navy background
- Hero section: clean with brand statement
- Products: table-based layout (professional B2B feel)
- Filter tabs: by category
- Currency toggle: UZS / USD

## Components
- ProductTable: showing all product columns with sorting
- CategoryFilter: tab-based filter (All / Cars / Animals)
- CurrencyToggle: switch between UZS and USD display
- PriceTag: formatted price display
- ContactSection: bottom CTA for wholesale inquiries

## Style Principles
- NO rounded card grids — use structured table/list layout (B2B feel)
- Clean whitespace, structured data
- Navy + white dominant, blue accents
- Professional typography, no playful fonts
- Subtle hover states on rows
- Mobile responsive

## Animations
- Subtle fade-in on page load
- Smooth currency switch transition
- Table row hover highlight
